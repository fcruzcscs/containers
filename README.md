# Containerfiles

This repository is a personal collection of containerfiles that are useful for testing, development, and experimentation. Each container lives in its own directory with a focused README describing its purpose, included tools, and basic usage.

## Available containers

- [`vscode-tunnel-rust`](./vscode-tunnel-rust/): Ubuntu 24.04 with the VS Code CLI and a minimal stable Rust toolchain, suitable for development through a VS Code tunnel.
